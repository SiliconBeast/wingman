# resume/

Scope reads two files from here. Neither is required, but the fit scores and ATS checks need the first.

- `resume.tex` is your current one-page resume, the same LaTeX you compile (a `resume.md` or `resume.txt` also
  works). Every scan scores each role's description against it, and the dashboard's ATS check loads it
  automatically. Update it whenever your real resume changes; scores recompute on the next scan.
- `bullets.md` is your bullet bank: real experience that doesn't fit on one page. The AI review draws on it when
  tailoring, so an RF posting can pull in your RF project. It is never counted in the fit score, because an
  applicant tracking system only sees your resume.

Keep the repository private: these files hold your contact details.
