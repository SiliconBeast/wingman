What You Will Do

Immerse yourself in a full-time, Monday-Friday co-op session, that will run January-August (including the Spring semester; it is expected students will take a semester off from coursework to fully engage with this working mentorship opportunity).

Do you want to build integrated systems on world-class Collins platforms? Do you enjoy pulling together a system to create a bigger picture? Do you enjoy networks and watching data flow through a system? With our system integration team, you will provide the operating environment for our application teams and support them with tools and troubleshooting for integration points between applications.

Our team works across engineering disciplines to deliver world-class avionics systems to warfighters on tankers, helicopter, and cargo aircraft.

•
You will assist our team in migrating software applications between operating systems and hardware environments.

•
You will build system configuration tables, identifying the inputs and tools from system requirements to enable end-to-end communication and application runtime environments.

•
You will configure and build helicopter system field-loadable software and help our team build on existing tools and practices for more consistent automation.

What You Will Learn

•
You will learn the artifacts for system configuration for Collins avionics hardware.

•
You will learn about the protocols used on the networks and buses between systems and subsystems in our avionics solutions.

•
You will learn the key software integration points for multiple avionics subsystems, including OS configurations, device drivers, network I/O, memory access, and avionics bus data access.
