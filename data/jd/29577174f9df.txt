IT Quality Assurance Intern (Summer 2027)

Position Summary

The IT QA Intern will support the testing team by executing scripted test cases, maintaining test documentation, and preparing test environments during active release cycles. This role provides hands-on exposure to enterprise software testing in a manufacturing IT environment while delivering measurable value to a lean, high-performing QA team.

Key Responsibilities

Test Execution & Documentation

Execute scripted test cases during release cycles and document pass/fail results with clear evidence

Flag defects or unexpected behaviors to senior QA analysts for triage

Test Case Maintenance

Review and update outdated test case steps to reflect current system behavior

Identify and flag orphaned test cases for review

Fill formatting gaps and standardize documentation across the test case library

Test Case Development Support

Map untested scenarios into draft test cases following team templates

Submit drafts to senior analysts for review and approval before use

Environment & Data Readiness

Set up test data per documented instructions to support upcoming test cycles

Reset and prepare test environments, reducing setup time

Verify environment readiness prior to release testing windows

Required Qualifications

Currently pursuing a Bachelor's degree in Computer Science, Information Technology, Information Systems, or related field

Coursework or demonstrated interest in software testing, QA, or software development lifecycle

Strong attention to detail and ability to follow documented procedures precisely

Clear written communication skills (test results must be unambiguous)

Ability to work independently on assigned tasks after initial training

Preferred Qualifications

Familiarity with test management tools (e.g., Jira, Azure DevOps, TestRail, or similar)

Exposure to cloud platforms (Salesforce, AWS, or Oracle)

Basic understanding of QA methodologies (test plans, test cases, defect lifecycle)

Interest in test automation concepts (Selenium, Playwright)

Experience with enterprise or ERP applications is a plus

What You'll Gain

Hands-on experience executing and documenting tests for enterprise-scale applications

Exposure to Oracle CPQ, cloud platforms, and manufacturing IT systems

Mentorship from senior QA analysts on testing best practices

Understanding of how QA integrates into release management and SDLC

Portfolio-ready work samples demonstrating real-world QA contributions
