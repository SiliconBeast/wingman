About this role:

Are you excited about innovation, entrepreneurship and solving complex business problems? Then we are looking for you!

The Data Engineer Intern supports data and software development initiatives by assisting with code debugging, performance improvements, and technical problem-solving. This role collaborates with team members to develop solutions, troubleshoot issues, and contribute to reliable data systems.

The intern also participates in code reviews, stays informed on emerging technologies, and helps ensure system understanding through ongoing documentation and project updates.

In this role you will:

• Debugging computer code to correct errors and improve performance

• Problem solving and solution creation

• Participating in peer code reviews to improve the quality of code written by team members

• Proactively learning about new technologies

• Regular communication and troubleshooting with team members

• Reviewing documentation about the latest technology releases and project updates to ensure understanding of system operations
