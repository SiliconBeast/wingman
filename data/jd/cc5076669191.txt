Job Description:

Job Description :
We are seeking a motivated undergraduate intern to join the Slingshot ASIC Firmware and Diagnostic team. The intern will contribute to firmware development in C, build and maintain Python-based diagnostic tooling, and support Linux-based development and testing. Embedded development experience is preferred. This is a hands-on role designed for students pursuing degrees in computer science or computer engineering.

Responsibilities :

• Write, test, and debug C code for Slingshot ASIC board firmware.

• Develop and maintain Python-based diagnostic tooling, data collectors, parsers, and test utilities.

• Create and maintain Bash scripts for automation, build processes, and test harnesses.

• Work in a Linux development environment; use Git for version control; contribute to and participate in code reviews.

• Help design, implement, and run automated tests and diagnostic workflows to validate firmware functionality.

• Collaborate with Hardware, Firmware, and Software teams to implement features and resolve issues.

• Document code, test plans, results, and user guides; contribute to internal knowledge base.

• Learn and apply ASIC firmware development practices, debugging techniques, and safety/compliance standards.

Education and Experience Required :

• Currently pursuing a Bachelor’s or Master’s degree in Computer Science, Computer Engineering, or Electrical Engineering (or equivalent).

• Working level knowledge with C programming, Python, Bash, and Linux.

• Demonstrated problem-solving, debugging, and analytical skills.

• Ability to work effectively in a team environment and communicate clearly.

• Familiarity with Git or other version control systems.

Preferred/Nice-to-Have Qualifications :

• Embedded development experience (course projects, internships, or personal projects).

• Exposure to embedded systems concepts, RTOS, device drivers, or microcontroller work.

• Basic understanding of build systems and continuous integration concepts.

• Experience with hardware peripherals (e.g., JTAG, I2C, SPI).

• Familiarity with automated testing frameworks and scripting for test automation.

Education Preference:

• Pursuing a degree in Computer Science or Computer Engineering.

• Relevant coursework or projects in firmware, embedded systems, or systems programming is a plus.
