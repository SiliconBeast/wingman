The Allied Solutions internship program is a robust and consistent internship program for juniors and seniors. The program will focus on learning and development as well as hands-on experience. The program will immerse the intern into a broad range of responsibilities, allowing you to ship work that reaches the clients who rely on our systems every day.

Interested applicants must be available during the 12-week program (May 17th – Aug. 6th, 2027). This is a full-time internship (40-hours per week) based at our headquarters in Carmel, IN.

The Software Engineer Intern will directly assist the Enterprise Technology Department with many software development projects. In this position, the intern will gain a better understanding of the role and gain hands-on experience to be better prepared to work in Software Engineering.

Job Duties and Responsibilities

•
Write code that satisfies the acceptance criteria of a user story, applying test-driven development to validate it with unit and integration tests

•
Help write user stories, including acceptance criteria that encapsulate the needs of the business

•
Debug code and analyze data, queries, and application behavior to diagnose defects and performance bottlenecks

•
Collaborate with developers, analysts, designers, and system owners in the SDLC process of new software programs and applications, and present your project results to the team at the end of the program

•
Software Development with .Net /C#, JavaScript (React.js or Angular.js), Python, and TSQL, including participation in code reviews and use of static analysis tooling such as SonarQube to keep code clean, secure, and maintainable

•
Utilize AI in your day-to-day tasks to aid in increasing efficiency, writing effective prompts and reviewing AI-generated code for correctness, security, and performance before it is submitted

•
Determine how to complete your work with a cloud native approach, helping modernize existing applications on AWS, delivering changes through CI/CD pipelines and feature flags, and using observability tooling to confirm your work behaves as expected
