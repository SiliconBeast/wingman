Job Description Summary
As an intern working on our proprietary workflow builder framework, you will expand the capabilities of that framework by applying software engineering principles in both the workflow framework itself and the Java code base behind it. Clinicians rely heavily on these workflows for repeatable, fast, and automated image processing. You’ll be advancing the best practices for this framework for testability and maintainability.

Job Description

What You'll Do:

•
Write automated tests for workflows that run calculations and automate displays

•
Evolve the framework for these automated tests for better usability and functionality

•
Update the backend of the workflow framework as needed

•
Work closely with experienced software engineers and workflow builders, including a personal mentor

•
Learn about software engineering principles in an industry environment

•
Learn about clinical uses of workflows

•
Learn about engineering best practices for development of regulated medical software

•
Work on real features with a real - world impact on customers

What You'll Need:

•
Some experience writing code , preferably in Java, from coursework, projects, or previous internships

•
An active pursuit of a bachelor's degree, preferably for computer science, computer engineering, biomedical engineering, electrical engineering, mathematics, or physics

•
General problem-solving skills

•
Strong analytical thinking

•
Communication and organization skills

•
An aptitude for math and science

•
An interest in exploring clinical use cases of medical imaging software

•
An existing understanding of medical imaging is not required
