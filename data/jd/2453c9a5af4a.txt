The Opportunity:

We are currently seeking a Fall Co-op in our Software Engineering department. As an Embedded Software Engineering Co-op, you will provide prototyping, coding, testing, scripting, and document generation in support of software development activities. The code will be developed in C++, C#, C, and Python and it will run on various types of hardware using Windows, Linux, or some sort of Real-Time Operating System (RTOS). Git along with either Bitbucket or GitLab will be used to track code changes. Jira will be used to track tasks and defects. You will submit your code for peer review prior to release. This will teach you the fundamentals of developing production quality code. You will benefit from working side-by-side with a talented and experienced group of professionals who are eager to mentor. Ideally, we'd like the candidate to join the team in August 2027 and continue through December 2027.

Responsibilities:

• Code development in C++, C#, C, and Python

• Software test development and execution

• Creation and updates for requirements, test plans, and release documentation

Qualifications:

• Ability to successfully complete a pre-employment drug screening

• Experience with programming in C++ or C#

• Interest in embedded programming and working with hardware

• Understanding of Object-Oriented Design

Desired:

• Experience programming in Python is preferred but not required

• Experience using the Unified Modeling Language (UML) is preferred but not required

• Minimum GPA of 3.0 or higher is preferred, but not required

• Previous internship/co-op or other work experience
