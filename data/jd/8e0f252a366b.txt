Role Overview

Our Genesys Cloud Workforce Engagement Management (WEM) - Quality Management (QM) team builds AI Scoring, Agent Evaluation and Survey solutions that help the world’s leading enterprise customers improve service delivery and customer satisfaction. Join us and help deliver products that enable supervisors to evaluate customer interactions (calls, chats, emails), score them using configurable rubrics, and drive coaching based on results and customer feedback. This role is a full-stack software development position involving the entire development lifecycle.

With our support, you’ll learn and grow in a fast-paced, AI driven environment focused on continuous improvement and innovation.

Responsibilities

• Build production features, backend flows, APIs and UIs in the evaluation, scoring, and survey path

• Deliver secure, scalable applications built on AWS infrastructure

• Build features with automated tests, participate in code reviews and debug issues

• Use AI developer tools to generate code faster, debug complex issues, and navigate a large production codebase with confidence

Qualifications

• Pursuing a bachelor’s degree in a software-related discipline

• Experience with a modern programming language like Java, Python, or JavaScript

• Interest in frontend, backend, or full-stack development

• Ability to communicate clearly and collaborate in a team environment

• Familiarity with web development fundamentals

Tech Stack

• You do not need full-stack experience coming in; interest in frontend, backend, or both is enough. You’ll have the opportunity to work with the following technologies:

• Backend: Java, Spring Boot, Python

• Frontend: JavaScript, TypeScript, HTML/CSS, React/Redux

• Cloud infrastructure: AWS (EC2, S3, Lambda, Bedrock, DynamoDB, SQS), Kafka, Redis

• AI Tools: Claude, Amazon Kiro
