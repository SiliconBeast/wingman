Role Overview:
Help build the next generation of web experiences and backend services that support more than 70 billion customer interactions across over 100 countries each year. As a Software Developer Intern, you will contribute production-quality code using modern frontend technologies, cloud services, and AI-enabled platforms while learning alongside experienced developers. You will work across the software development lifecycle, gaining practical exposure to scalable web applications, backend services, automated testing, and AWS technologies. At Genesys, your work will help organizations deliver more connected and effective customer experiences while expanding your skills through hands-on engineering, peer collaboration, and exposure to enterprise-scale initiatives.

Key Responsibilities:

•
Develop production-quality, responsive web applications and backend services that improve the usability, performance, and scalability of Genesys products

•
Contribute to next-generation Web UIs using modern JavaScript and TypeScript technologies, including Vue.js

•
Implement product enhancements and resolve software defects while maintaining code quality, reliability, and maintainability

•
Build unit tests and automation that strengthen software quality and support efficient development and release processes

•
Collaborate with experienced developers through code reviews, technical discussions, and agile development practices

•
Apply AWS services such as EC2, Lambda, DynamoDB, S3, and SQS to support scalable cloud-based applications

•
Improve engineering practices by contributing ideas, learning from peer feedback, and participating in continuous improvement

•
Expand technical capabilities through hands-on experience with enterprise-scale cloud applications and modern software development practices
