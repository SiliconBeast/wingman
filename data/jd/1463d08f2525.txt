Role Overview

At Qualcomm Canada, our Mixed Signal IP Firmware and Embedded Software team in Toronto develops the embedded software that powers Qualcomm’s high-performance, multi-standard SerDes PHY and die-to-die interconnect IP. Our IP supports standards such as PCIe, Ethernet, CXL, and UCIe and is integrated into SoCs, ASICs, and chiplets for AI data center , networking, and compute applications.

The team owns the full embedded software stack that controls the hardware, including low-level firmware running on RISC-V-based controllers, customer-facing C and Python SDKs, lab tools and GUIs for interactive debug, and the build, regression, and continuous integration infrastructure that keeps our releases healthy. We are a key enabler of silicon bring-up, validation, and production deployment, and we work closely with digital design, design verification, silicon validation, systems, and DevOps teams.

Under the guidance of an experienced engineer and a dedicated mentor, interns contribute directly to shipping firmware and SDK releases. This posting covers two project areas on the same team: Embedded Firmware and SDK Development, and Firmware Tooling, Test Automation, and CI. Candidates will be considered for both areas, with the final match determined during the interview process.

No prior semiconductor background is required. Through hands-on work, you will learn how software and silicon interact and how a feature progresses from simulation to emulation and real silicon in the lab.

 

Responsibilities may include:

•
Writing and debugging low-level C firmware and device drivers that configure, calibrate, monitor, and control high-speed SerDes and die-to-die interconnect hardware

•
Extending customer-facing C and Python SDK features for link bring-up, calibration, tuning, diagnostics, error monitoring, and register access

•
Porting and optimizing firmware so that it runs consistently across simulation, emulation, FPGA, and real-silicon environments

•
Building Python tooling, lab automation, regression tests, and test frameworks that improve firmware quality and development efficiency

•
Improving build, release, and continuous integration flows used to validate firmware and software across multiple hardware platforms

•
Developing interactive debug tools, command-line utilities, GUIs, and dashboards that make link health and test coverage visible

•
Investigating firmware, software, and hardware integration issues and driving them toward root cause with cross-functional engineering teams

•
Working in the lab alongside firmware, design, verification, systems, and validation engineers to bring up and debug silicon

•
Contributing to technical documentation, code reviews, test plans, and reliable firmware and SDK releases
