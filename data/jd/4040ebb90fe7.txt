Job Summary
As an IT Software Engineer Intern at Vermeer, you will gain hands‑on experience designing and supporting modern software solutions that strengthen business operations across the organization. You’ll collaborate with experienced engineers, practice foundational development concepts, and contribute to real product enhancements while building skills in cloud technologies, application development, and team‑based Agile delivery.

What You’ll Do:

1. Contribute to software development tasks using object‑oriented programming concepts and languages such as C#, .NET, JavaScript, or TypeScript. You will assist in writing clean, maintainable code that supports application functionality and user experience.

2. Support the creation and testing of Representational State Transfer (RESTful) Application Programming Interfaces (APIs) and cloud services hosted within Microsoft Azure. This includes practicing secure coding and basic debugging techniques.

3. Participate in source control processes and introductory Continuous Integration/Continuous Deployment (CI/CD) workflows, using automated build and test activities under the guidance of senior developers.

4. Assist in working with relational and non‑relational databases to retrieve, validate, and prepare data that supports application features and integrations.

5. Join Agile ceremonies such as sprint planning, standups, and retrospectives to gain experience with iterative development and collaborative team delivery.

6. Document findings, update reference materials, and help troubleshoot simple issues to support the overall software development lifecycle.

7. Explore emerging technologies and modern engineering practices while applying classroom learning to real‑world scenarios.

What We’re Looking For:

- Currently pursuing a Bachelor’s degree in Information Technology, Computer Science, Software Engineering, or a related field.

- Exposure to web development or application frameworks using languages such as C#, .NET, JavaScript, or TypeScript through coursework or project work.

- Familiarity with RESTful APIs, cloud concepts, or CI/CD basics, with willingness to strengthen these skills through hands‑on practice.

- Understanding of standard data formats, including JavaScript Object Notation (JSON) and Extensible Markup Language (XML).

- Strong curiosity, initiative, and willingness to learn new tools and approaches in a collaborative environment.

- Clear communication skills, professionalism, and ability to work productively with technical and nontechnical partners.

- Interest in problem‑solving and continuous learning within modern software engineering disciplines.
