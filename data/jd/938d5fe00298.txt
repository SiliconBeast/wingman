POSITION SUMMARY

The Applied Science and AI team at Abiomed is looking for an Co-Op to help us build the next generation of cutting-edge tools. The candidate will work with our team to develop and test various software components for an upcoming class III medical device. This is an excellent opportunity to learn valuable skills while contributing to a

new product release.

KEY RESPONSIBILITIES:

The student will:

• Support a productive and innovative team, including working with peers, managers, and different teams.

• Assist in connecting/integrating new data sources into existing architecture.

• Designing, developing and testing software solutions utilizing Agile methodologies and software engineering principles while conforming to existing code development strategies and processes

• Assisting in various software engineering activities such as algorithm & data analysis, software/system troubleshooting, and supporting documentation in accordance with established procedures.

• Support informal and formal software verification, validation, and integration testing.

REQUIREMENTS:

• Currently enrolled in a Bachelor's or Master’s degree in Computer Science Or Biomedical Engineering or

• related programs

• Familiarity with Linux OS and at least one web UI framework (such as Angular)

• Coding experience in one of the following programming languages: Javascript, C, Lua or Rust.

• Familiarity with basic statistical analysis.

• Self-motivated, execute tasks with attention to detail in a timely manner.

• Demonstrated communication skills, both written and verbal.

• Proficiency in Microsoft Office products

PREFERRED:

• Experience with a version control system (Git) through project/coursework.

• Contributes to opensource projects or has a personal project portfolio
